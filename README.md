# LoyaltyForge — Restaurant Digital Loyalty & QR Generator Platform

Built strictly on **Drive F** (`F:\antigravity_workspace\pennyworth_automation\loyalty card automation\`) following the **WAT (Workflows, Agents, Tools) framework**.

## Project Architecture
- **`workflows/`**: Standard Operating Procedures (SOPs) for Pass Creation, Standee Generation, Cashier Stamping, and Retention Marketing.
- **`tools/`**: Deterministic Python and JavaScript tools for vector QR generation, PDF standees, math calculations, and WhatsApp outreach builders.
- **`src/`**: Modern React + Vite web platform featuring Card Studio, Live Apple & Google Wallet simulators, Printable Table Tent Kit, Customer Mobile Pass PWA, Cashier POS Terminal, and Marketing CRM.
- **`data/`**: Seeded restaurant templates and customer loyalty database.

## Quick Start
```bash
npm install
npm run dev
```
Open **`http://127.0.0.1:5173`** in your browser.
